# HW1 - 台灣人口變化 D3.js 靜態視覺化

## 題目
台灣人口連續 32 個月負成長：2026 年 8 月部分縣市人口年增減率比較

## 執行方式
1. 用 VS Code 開啟此資料夾。
2. 對 `index.html` 按右鍵。
3. 選擇 `Open with Live Server`。
4. 瀏覽器即可看到圖表。

## 檔案
- `index.html`：D3.js 主程式與網頁內容
- `style.css`：版面與圖表樣式
- `data.csv`：縣市人口年增減率
- `作業說明.txt`：可供繳交報告或口頭說明使用

## 視覺化內容
- 發散型水平長條圖
- 0% 基準線
- 正值：人口增加
- 負值：人口減少
- 數值標籤
- 靜態資訊摘要卡片

## 資料來源
- 內政部戶政司：民國 115 年 8 月戶口統計資料分析
- 聯合新聞網：2026/09/10 人口負成長相關新聞
